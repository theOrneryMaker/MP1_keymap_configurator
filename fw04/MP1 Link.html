No Link

First time: Connect… and pick the macropad's port. After that it connects by itself.

Profile

Connect to see the macropad's profiles.

Click one to switch: the macropad shows that profile's layers at once (ALL shows every layer). Clicking the profile name at the top of the player goes to the next one.

This computer

Whenever the macropad connects to this page on this computer, it switches to this profile by itself: work layers hidden at home, game layers hidden at work. Kept in this computer's browser, so each computer has its own. Without the page open, the macropad keeps the profile it had last. Any leaves the profile alone.

Instead of the Run dialog (Win+R), a key's web address opens as a new tab here: quicker, and nothing flashes up on the screen. The first time, the browser may block it (a "pop-up blocked" icon in the address bar): click it and choose Always allow. Until then, and whenever this page isn't connected, the macropad uses the Run dialog as before.

Sent when it connects and every hour; kept until the macropad loses power. Modules can use it (mp.time()).

Mini window on the desktop

It opens this file as a small app window showing only the player (any window narrower than about 520 pixels does the same). Open mini window above keeps it on top of other windows. If you move this file, make the shortcut again. Chrome works too: use chrome.exe instead of msedge.exe.
