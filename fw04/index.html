Changes to test

2026-11-16

  • FIXEDStatus row: the timer no longer runs into the encoder's icons. The countdown and stopwatch now sit at the right of the status row, just left of the Caps / Num marks, and are never more than 5 characters, so they always clear the encoder's label even with two icons and 4 letters. The stopwatch there shows just the time (12:34, or 1:02h past an hour) instead of SW 12:34. Needs the new UF2 above (flash it again).
  • FIRMWAREFirmware batch: layer cards, two encoder icons, Layer Keys, hold icons, secret icons, built-in boot pictures. Needs the firmware 04 test build above (flash the UF2, then the custom zip). Layer card: switching layers with a key now shows the layer's card (its icon and name, or its picture), like the layer picker. Encoder: its icons are full 16 × 16, and it can have two: in its icon editor pick Icon 1 or Icon 2, then an icon (the Pixels tab's status size is 16 × 16 now). Layer Keys: turn the encoder to move a box from layer to layer (the page follows), click to go there, hold to go back; the keys still work; a layer with an icon shows it on its key. Hold screen: a HOLD+KEY slot's icon (Settings tab, Key action…) shows there; saving Settings updates the pad's icons when the keymap was opened from the same drive. Secret layers: their icons now show on the pad; they're kept inside the encrypted secret.json (saving them needs MP1 Link, like the secret layers themselves). Boot pictures: the default ones are built into the firmware and no longer listed in Drop-ins; only your own show there.
  • NEWFix a key's whole label, pixel by pixel. Click a key's label picture, then Fix the whole label…: its letters and icons open as one 30 × 24 picture in the pixel editor (Draw, Select and move, Invert, Clear, As converted to start over). After Use these pixels the key's tile, the screen preview and the Link player show your version, and Save to drive sends it to the pad as the key's label (works with the firmware already on the pads). Change the key's text or icons and the fix no longer applies; Undo the label fix removes it.
  • NEWShortcut icons for MP1 and MP1 Link. The Toolkit folder now has mp1_link.ico (the pad's screen with four keys) next to mp1.ico (the four keys), both sharp at every Windows size up to 256 px. Download them from the Pages list above to try now. To set one: right-click the shortcut → Properties → Change Icon… → Browse…, pick the .ico. Help explains it too (keep the .ico next to the shortcut so it stays when the pad is unplugged).
  • NEWLink screens: original icons, or the pad's pixels with your edits. Settings tab > MP1 Link displays (also in the player's gear menu as Icons; remembered in this browser): As on the pad or Original icons. Original draws the icons smooth on the Link player, mini windows and skins, so a conversion that came out rough doesn't matter there; the letters stay in the pad's font. As on the pad now also uses your pixel edits (it reads icons/edits.json from the pad), where before it showed the plain conversion. The key label previews in the Keymap tab always show the pad's pixels.
  • NEWPixel editors: Select tool. In the Pixels tab (Select, next to Box) and the icon Pad pixels pop-up (Draw / Select): drag a box around some pixels, then move just that block with the arrow buttons, the arrow keys (hold Shift for 4 pixels at a time) or by dragging inside the box. Black pixels in the block are see-through, and pixels pushed off the edge come back if you move them back. Delete clears the block, Esc lets go, Undo takes back a whole move.
  • FIXEDKeymap tab: macros had no room to edit. In Pad view each key card now shows its label and a one-line summary ("Macro (4 steps)", "Key: Enter"). Click the summary and the key's editor opens under its row at full width; click it again or ✕ to close. Small icons on the card show Hold to confirm and Repeat. List view is unchanged.
  • FIXED"Couldn't use keymap.json from the drive: Not a version 2 keymap" when the page opened by itself next to a pad whose keymap is split into layer files (keymap.json version 3). The automatic open now reads the layer files, like Open from drive does.
