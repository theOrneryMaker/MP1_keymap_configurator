Changes to test

2026-11-16

  • NEWShortcut icons for MP1 and MP1 Link. The Toolkit folder now has mp1_link.ico (the pad's screen with four keys) next to mp1.ico (the four keys), both sharp at every Windows size up to 256 px. Download them from the Pages list above to try now. To set one: right-click the shortcut → Properties → Change Icon… → Browse…, pick the .ico. Help explains it too (keep the .ico next to the shortcut so it stays when the pad is unplugged).
  • NEWLink screens: original icons, or the pad's pixels with your edits. Settings tab > MP1 Link displays (also in the player's gear menu as Icons; remembered in this browser): As on the pad or Original icons. Original draws the icons smooth on the Link player, mini windows and skins, so a conversion that came out rough doesn't matter there; the letters stay in the pad's font. As on the pad now also uses your pixel edits (it reads icons/edits.json from the pad), where before it showed the plain conversion. The key label previews in the Keymap tab always show the pad's pixels.
  • NEWPixel editors: Select tool. In the Pixels tab (Select, next to Box) and the icon Pad pixels pop-up (Draw / Select): drag a box around some pixels, then move just that block with the arrow buttons, the arrow keys (hold Shift for 4 pixels at a time) or by dragging inside the box. Black pixels in the block are see-through, and pixels pushed off the edge come back if you move them back. Delete clears the block, Esc lets go, Undo takes back a whole move.
  • FIXEDKeymap tab: macros had no room to edit. In Pad view each key card now shows its label and a one-line summary ("Macro (4 steps)", "Key: Enter"). Click the summary and the key's editor opens under its row at full width; click it again or ✕ to close. Small icons on the card show Hold to confirm and Repeat. List view is unchanged.
  • FIXED"Couldn't use keymap.json from the drive: Not a version 2 keymap" when the page opened by itself next to a pad whose keymap is split into layer files (keymap.json version 3). The automatic open now reads the layer files, like Open from drive does.
